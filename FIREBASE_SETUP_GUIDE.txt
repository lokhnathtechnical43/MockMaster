=====================================================
  FIREBASE COMPLETE SETUP GUIDE - ExamPrep Bharat
=====================================================

তোমার প্রজেক্টে কোড তো হয়ে গেছে, কিন্তু Firebase
Console-এ সেটআপ করা বাকি। এই গাইড ধাপে ধাপে ফলো করো।

=====================================================
  ধাপ ১: Firebase প্রজেক্ট তৈরি
=====================================================

1. ব্রাউজারে যাও: https://console.firebase.google.com
2. Google account দিয়ে login করো
3. "Create a project" বা "Add project" ক্লিক করো
4. Project name দাও: examprep-bharat (বা তোমার পছন্দের নাম)
5. "Continue" ক্লিক করো
6. Google Analytics: Enable করো (optional, recommended)
7. "Create project" ক্লিক করো → Wait for setup
8. "Continue" ক্লিক করো

=====================================================
  ধাপ ২: Web App রেজিস্টার করো (API Keys পাওয়ার জন্য)
=====================================================

1. Project Overview পেজে ⚙️ (Gear icon) → "Project settings"
2. নিচে স্ক্রল করো → "Your apps" সেকশন
3. Web icon (</>) ক্লিক করো
4. App nickname দাও: examprep-bharat-web
5. "Also set up Firebase Hosting" — চেক রাখো (optional)
6. "Register app" ক্লিক করো
7. firebaseConfig object দেখাবে — এটা কপি করো!

   এরকম দেখাবে:
   const firebaseConfig = {
     apiKey: "AIzaSy...",
     authDomain: "examprep-bharat.firebaseapp.com",
     projectId: "examprep-bharat",
     storageBucket: "examprep-bharat.firebasestorage.app",
     messagingSenderId: "739166898850",
     appId: "1:739166898850:web:..."
   };

8. এই values গুলো .env.local ফাইলে বসাও:

   /home/z/my-project/.env.local

   NEXT_PUBLIC_FIREBASE_API_KEY=AIzaSy...
   NEXT_PUBLIC_FIREBASE_AUTH_DOMAIN=examprep-bharat.firebaseapp.com
   NEXT_PUBLIC_FIREBASE_PROJECT_ID=examprep-bharat
   NEXT_PUBLIC_FIREBASE_STORAGE_BUCKET=examprep-bharat.firebasestorage.app
   NEXT_PUBLIC_FIREBASE_MESSAGING_SENDER_ID=739166898850
   NEXT_PUBLIC_FIREBASE_APP_ID=1:739166898850:web:...

9. Dev server restart করো: npm run dev

=====================================================
  ধাপ ৩: Firestore Database চালু করো
=====================================================

1. Firebase Console এ যাও
2. বামে "Firestore Database" ক্লিক করো
3. "Create Database" ক্লিক করো
4. Mode সিলেক্ট করো:
   - ডেভেলপমেন্টের জন্য: "Start in test mode" (সব কেউ access করতে পারবে)
   - প্রোডাকশনের জন্য: "Start in production mode" (rules লাগবে)
5. Location সিলেক্ট করো:
   - india-র জন্য: asia-south1 (Mumbai) বা asia-south2 (Delhi)
   - ⚠️ একবার সিলেক্ট করলে আর পরিবর্তন করা যাবে না!
6. "Done" ক্লিক করো

=====================================================
  ধাপ ৪: Firebase Authentication চালু করো
=====================================================

1. Firebase Console → "Authentication" ক্লিক করো
2. "Get started" ক্লিক করো
3. "Sign-in method" ট্যাবে যাও
4. "Email/Password" provider এ ক্লিক করো
5. "Enable" toggle ON করো
6. "Save" ক্লিক করো

⚠️ তুমি প্রথম test user অ্যাপ থেকেই Sign Up করতে পারবে!

=====================================================
  ধাপ ৫: Firebase Storage চালু করো (ইমেজ আপলোডের জন্য)
=====================================================

1. Firebase Console → "Storage" ক্লিক করো
2. "Get started" ক্লিক করো
3. Security rules সিলেক্ট:
   - Test mode: start in test mode (ডেভেলপমেন্টের জন্য)
   - Production: signed-in users only
4. Location: Firestore এর একই location সিলেক্ট করো
5. "Done" ক্লিক করো

=====================================================
  ধাপ ৬: Firestore Security Rules Deploy করো
=====================================================

প্রজেক্টে তোমার জন্য rules ফাইল তৈরি করা আছে।
Deploy করতে:

Option A: Firebase CLI দিয়ে (recommended)
1. npm install -g firebase-tools
2. firebase login
3. firebase init → Firestore rules সিলেক্ট
4. firebase deploy --only firestore:rules

Option B: Firebase Console এ manually
1. Firestore Database → Rules ট্যাব
2. firestore.rules ফাইলের content কপি-পেস্ট করো
3. "Publish" ক্লিক করো

=====================================================
  ধাপ ৭: Firestore-এ Data Seed করো
=====================================================

Firebase Console সেটআপ হয়ে গেলে:

1. Dev server চালু করো: npm run dev
2. ব্রাউজারে যাও: http://localhost:3000/admin
3. Login করো (password: admin123)
4. "Settings" ট্যাবে যাও
5. "Test Connection" ক্লিক করো → Connected দেখাবে
6. "Use Firestore" toggle ON করো
7. "Seed Firestore from Local Data" ক্লিক করো
8. সব exam data Firestore-এ upload হয়ে যাবে!

=====================================================
  ধাপ ৮: Verify করো সব কাজ করছে
=====================================================

1. Firebase Console → Firestore Database → Data ট্যাব
   - categories, exams, tests, questions collections দেখাবে

=====================================================
  TROUBLESHOOTING
=====================================================

Problem: "Firebase: Error (auth/operation-not-allowed)"
Solution: Firebase Console → Authentication → Email/Password provider ON করো

Problem: "Firebase: Error (auth/email-already-in-use)"
Solution: এই email দিয়ে আগেই account আছে, Login করো

Problem: "Firebase: Error (auth/weak-password)"
Solution: Password কমপক্ষে ৬ অক্ষরের হতে হবে

Problem: "Firebase: Error (auth/invalid-credential)"
Solution: Email বা password ভুল আছে, আবার চেষ্টা করো

Problem: "Firestore: Missing or insufficient permissions"
Solution: firestore.rules deploy করো (ধাপ ৬)

Problem: Connection test failed
Solution:
  1. .env.local এ সব values সঠিক আছে কিনা check করো
  2. Dev server restart করো
  3. Firestore Database created আছে কিনা verify করো

Problem: Seed কাজ করছে না
Solution:
  1. Firestore ON করো Settings এ
  2. Connection test pass করো
  3. Console এ error দেখো
